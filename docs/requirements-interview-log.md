# JanitorJAV V1 需求访谈记录

日期：2026-09-01 至 2026-09-02  
方式：逐题 Grill 需求访谈  
状态：用户已确认共同理解

本文记录需求访谈中的关键问题与最终决定。它用于说明 V1 规格的决策来源；发生冲突时，以 [V1 产品与技术规格](v1-specification.md) 为准。

## 目标与识别边界

| 编号 | 问题 | 确认结论 |
| --- | --- | --- |
| Q1 | 漏检和误报如何取舍 | 优先高召回；结果只进入人工审核，不自动删除。 |
| Q2 | 普通剧情中的赌场场景是否考虑 | 不考虑；目标广告具有清晰中文和网址，赌场剧情场景基本不存在。 |
| Q3–Q4 | 是否按广告持续时间判断 | 不关心持续时间；任意一张实际抽样帧命中即可。 |
| Q5–Q7 | 抽帧策略 | 最初讨论少量特殊点位，随后调整为固定秒数和百分位组合。 |
| Q8 | 网址是否必须确认属于博彩网站 | 不需要；任意网址均标记。 |
| Q41–Q43 | 什么算网址 | 出现点分结构即算，允许两字符后缀；IPv4 也算；区分高、低置信度。 |
| Q73 | 是否对图片做多路增强 OCR | V1 暂不做，只识别原始抽帧。 |

## 抽帧与短视频

| 编号 | 问题 | 确认结论 |
| --- | --- | --- |
| Q8–Q9 | 最终抽帧点 | 5、10、15、20、25 秒，以及 10%、25%、50%、75%、90%。 |
| Q9、Q69 | 无效和重复点位 | 超出有效时长的点位丢弃；0.5 秒内的点位合并；短视频可少于 10 帧。 |
| Q10 | 小于 3 分钟的视频 | 直接标记，同时仍抽帧和 OCR，保留辅助证据。 |
| Q30 | 保存哪些抽帧 | 保存全部实际抽取的帧。 |

## 文件发现和资产分组

| 编号 | 问题 | 确认结论 |
| --- | --- | --- |
| Q11–Q12 | 扫描范围和视频发现 | 扫描全部子目录；扩展名白名单初筛，再由 ffprobe 验证。 |
| Q16 | 隔离时如何处理关联文件 | 以视频资产组为单位，关联文件共同带标和处理。 |
| Q16–Q17 | 同目录多个视频及 CD 分段 | 带 `-CD数字` 的分段组成一组，任一分段命中则整组命中；无 CD 的视频独立。 |
| Q18 | MDC 配套文件命名 | NFO 与视频同名，图片为 `-poster`、`-fanart`、`-thumb`。 |
| Q19–Q21 | 字幕关联 | 严格匹配视频同名字幕或 `.AI` 字幕；附加语言后缀不在当前媒体库范围内。 |
| Q36 | 缺少配套文件的视频 | 仍扫描并形成不完整资产组；缺少的 NFO/图片分别打标。 |
| Q70 | 什么是最终层资产目录 | 任何直接含视频的目录都算资产目录，即使还有子目录；仍继续递归。 |
| Q71 | 额外子目录 | 算剩余非系统内容，整体隔离时随目录移动。 |

## CD 和 VR 命名

| 编号 | 问题 | 确认结论 |
| --- | --- | --- |
| Q17 | CD 大小写和格式 | 大小写不敏感，识别独立的 `-CD数字` 标记。 |
| Q77 | VR 跳过范围 | VR 仍读取时长、分辨率和资产完整性，但跳过抽帧、OCR 和短视频广告规则。 |
| Q78 | CD 套装中的 VR | 任一分段带 VR，则整套按 VR 跳过；命名不一致另行标记。 |
| Q79 | VR/CD 标记位置 | 两者可以位于文件名任意连字符分段位置，顺序不限；解析后生成组键。 |

## 格式、元数据和标签

| 编号 | 问题 | 确认结论 |
| --- | --- | --- |
| Q14 | 无法处理的视频如何表达 | 各种特殊规则和技术失败分别独立打标，最后通过筛选决定。 |
| Q75 | RM/RMVB | 始终带旧格式标签，同时继续尝试探测、抽帧和 OCR；失败标签叠加。 |
| Q76 | 时长和分辨率 | 记录为元数据并支持筛选、排序；支持预设分辨率档位和精确范围。 |
| Q85 | 是否解析 NFO | V1 不解析，只用于资产完整性和随组移动。 |

## 本地 OCR 和运行环境

| 编号 | 问题 | 确认结论 |
| --- | --- | --- |
| Q22–Q23 | 本地或接口 OCR | 完全使用本地 OCR，不接模型接口；优先支持 GPU。 |
| Q24 | 运行环境 | Windows + NVIDIA GPU。 |
| Q25 | Docker/WSL 或原生 | Windows 原生。 |
| Q26 | 交付形态 | V1 可用 Python 环境和一键启动脚本，不要求单文件 EXE。 |
| Q80 | 多 GPU | 启动时列出 CUDA 设备，可选择 GPU；失败时不静默降级。 |
| Q81 | 并发 | 提供保守、平衡、高性能和自定义并发，默认平衡。 |

## Web 审核界面

| 编号 | 问题 | 确认结论 |
| --- | --- | --- |
| Q13 | 审核入口 | 使用仅本机访问的 Web 审核界面。 |
| Q31 | 显示全部或仅命中 | 保存全部记录；默认显示有标签项，可切换全部。 |
| Q33 | 审核状态 | 待审核、确认保留、准备隔离、已隔离、隔离失败；后来增加已恢复。 |
| Q49 | 批量操作 | 按标签等条件筛选，支持批量保留和准备隔离。 |
| Q50 | 分页 | 服务端分页；默认 50 条，可选 25、50、100；支持整页全选。 |
| Q51–Q53 | 图片和文件打开 | 列表不预加载图片；点击帧链接在浮窗或新页预览，并显示 OCR 依据；点击最终层目录在资源管理器打开。 |
| Q54 | CD 展示 | 整套 CD 只占一条记录，内部展示全部分段及证据。 |

## 目录级判断

| 编号 | 问题 | 确认结论 |
| --- | --- | --- |
| Q35–Q40 | 何时整体标记目录 | 所有资产组准备隔离后，判断剩余内容；只剩系统杂项时视为实际为空，存在其他内容时列出备注并额外确认。 |
| Q37、Q39–Q40 | 整体隔离内容 | 确认整体隔离后移动整个目录，包括系统杂项、剩余文件和子目录。 |
| Q72 | 系统杂项 | 忽略 `.DS_Store`、`Thumbs.db`、`desktop.ini`、`._*` 以及常见系统目录；列表可配置。 |
| Q87 | 目录判断时机 | 根据用户实际选择“准备隔离”的资产组动态计算，而不是仅按自动检测标签计算。 |

## 任务、记录与恢复

| 编号 | 问题 | 确认结论 |
| --- | --- | --- |
| Q27 | 是否跨任务增量扫描 | 不需要；每个新任务都全量扫描选定目录。 |
| Q28–Q29 | 记录方式 | 不使用数据库；使用结构化 JSONL、普通日志和证据目录，历史任务可重新载入。 |
| Q32 | 中断恢复 | 同一任务支持断点续扫；与跨任务增量无关。 |
| Q52 | 长任务控制 | 显示进度，支持暂停、继续、安全取消；页面关闭不影响后台。 |
| Q56–Q57 | 工作目录和清理 | 默认 `%LOCALAPPDATA%\JanitorJAV\tasks\<任务ID>`；不自动清理，由用户手动删除。 |
| Q83 | 完成通知 | Web 摘要和 Windows 本地通知，不接外部服务。 |
| Q84 | 开机启动 | 不需要。 |

## SMB 与隔离区

| 编号 | 问题 | 确认结论 |
| --- | --- | --- |
| Q58 | 网络共享 | 媒体库位于 SMB 路径，必须支持 UNC 或映射盘。 |
| Q59 | SMB 认证 | 只使用 Windows 当前会话，不保存凭据。 |
| Q60 | 网络临时失败 | 自动重试 3 次，失败后打标并继续；支持仅重试失败项。 |
| Q61–Q63 | 隔离位置 | 隔离区与扫描根必须是同一直接父目录下的兄弟目录；不做跨盘复制。 |
| Q63、Q67 | 隔离区名称 | 固定为 `JanitorJAV_Quarantine`，不可配置。 |
| Q64–Q66 | 隔离目录状态 | 不存在时自动创建；存在时必须为空；同任务内保留结构并合并目标子目录。 |
| Q68 | 下一任务前的处理 | 用户人工检查、移走、改名或清空隔离区；程序不自动清理。 |
| Q74 | 隔离事务 | 审核单元全成或全败；失败时尽力回滚。 |
| Q82 | 扫描后文件变化 | 隔离前复核文件清单、大小和修改时间；变化则停止并标记。 |
| Q86 | 恢复 | 支持按资产组、CD 套装或整体目录恢复；冲突时不覆盖。 |

| 编号 | 问题 | 确认结论 |
