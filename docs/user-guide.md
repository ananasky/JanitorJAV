# JanitorJAV 使用指南

本文包含 JanitorJAV V1 计划中的正式使用流程，以及当前开发预览版本的本地验证方法。

> 当前状态：扫描核心正在开发中。Web 审核界面、Windows CUDA OCR、完整任务调度、隔离和恢复尚未全部可用。请勿将当前代码直接用于移动正式媒体库文件。

## 1. V1 适用场景

JanitorJAV 用于全量扫描经过 MDC 整理的 JAV 媒体库，并标记：

- 抽样画面中包含网址或 IPv4 地址的视频；
- 时长小于 3 分钟的非 VR 视频；
- RM/RMVB 等旧格式视频；
- 无法探测、抽帧或 OCR 的视频；
- 缺少 NFO、海报、背景图或缩略图的不完整资产组。

系统不会自动删除文件。用户审核后，文件只会移动到同级的 `JanitorJAV_Quarantine` 隔离目录。

## 2. 支持的媒体库结构

扫描根目录下可以存在任意层级的分类目录。任何直接包含视频的目录都会被视为资产目录。

标准单视频资产示例：

```text
ABC-123 番号片名/
  ABC-123.mp4
  ABC-123.nfo
  ABC-123-poster.jpg
  ABC-123-fanart.jpg
  ABC-123-thumb.jpg
  ABC-123.srt              # 可选
  ABC-123.AI.srt           # 可选，AI 字幕
```

CD 分段示例：

```text
ABC-123 番号片名/
  ABC-123-CD1.mp4
  ABC-123-CD1.nfo
  ABC-123-CD1-poster.jpg
  ABC-123-CD1-fanart.jpg
  ABC-123-CD1-thumb.jpg
  ABC-123-CD2.mp4
  ABC-123-CD2.nfo
  ABC-123-CD2-poster.jpg
  ABC-123-CD2-fanart.jpg
  ABC-123-CD2-thumb.jpg
```

`VR` 和 `CD数字` 都按大小写不敏感的独立连字符标记识别，可位于主文件名中的不同位置，例如：

- `ABC-123-VR-CD1.mp4`
- `ABC-123-CD1-VR.mp4`

任意 CD 分段命中后，整套 CD 会作为一个审核单元。VR 资产只读取元数据和检查配套文件，不执行抽帧和 OCR。

## 3. 目标运行环境

正式 V1 的目标环境：

- Windows 10 或 Windows 11；
- Python 3.11 或更高版本；
- NVIDIA 显卡及兼容的 CUDA 环境；
- FFmpeg 和 ffprobe；
- 可访问媒体库 SMB 共享的 Windows 用户会话；
- Chromium、Edge 或 Firefox 等现代浏览器。

JanitorJAV 不保存 SMB 用户名或密码。请先在 Windows 中打开或挂载共享，确认当前用户能够读取媒体库。

## 4. 安装准备

以下是 V1 预定流程，最终安装脚本完成后会进一步简化。

### 4.1 获取代码

```powershell
git clone https://github.com/ananasky/JanitorJAV.git
cd JanitorJAV
```

### 4.2 创建 Python 环境

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install -e ".[dev]"
```

当前依赖只包含开发和测试基础。CUDA OCR 依赖将在 OCR 适配器完成后补充。

### 4.3 检查 FFmpeg

```powershell
ffmpeg -version
ffprobe -version
```

两条命令都必须能从 PowerShell 直接运行。Windows 最终版会提供环境检查并显示实际路径。

### 4.4 运行测试

```powershell
.venv\Scripts\python -m pytest
```

## 5. 正式 V1 操作流程

本节描述 V1 完成后的目标使用方式；当前开发预览尚未提供全部页面和操作。

### 5.1 启动

1. 双击项目提供的一键启动脚本。
2. 等待环境检查完成。
3. 浏览器自动打开仅本机访问的审核页面。
4. 页面应显示 FFmpeg、ffprobe、OCR、CUDA 和可用 GPU 状态。

### 5.2 创建扫描任务

1. 选择媒体库扫描根目录，例如 `\\server\media\JAV`。
2. 程序自动确定隔离目录：`\\server\media\JanitorJAV_Quarantine`。
3. 隔离目录必须不存在或为空；非空时任务不能启动。
4. 程序自动创建隔离目录并验证写权限。
5. 选择 CUDA GPU。
6. 选择保守、平衡、高性能或自定义并发模式。
7. 开始完整扫描。

扫描根与隔离根必须是同一直接父目录下的兄弟目录。程序不支持跨盘或跨共享隔离。

### 5.3 扫描期间

页面显示：

- 已发现和已完成的视频数量；
- 当前处理文件；
- 命中资产组数；
- 异常数；
- 当前吞吐量；
- 已用时间和预计剩余时间。

可执行：

- 暂停；
- 继续；
- 安全取消；
- 关闭浏览器后稍后重新打开；
- 程序重启后继续同一未完成任务；
- 扫描完成后只重试失败项。

每个新任务始终重新完整扫描，不使用旧任务结果跳过文件。

### 5.4 审核结果

默认只显示带标签的资产组，也可以切换到全部结果。

列表支持：

- 每页 25、50 或 100 条，默认 50 条；
- 当前页全选；
- 按标签、格式、状态、目录、置信度筛选；
- 按时长和分辨率范围筛选；
- 按常见分辨率档位筛选；
- 批量确认保留或准备隔离。

每条记录提供：

- 视频或 CD 套装信息；
- 时长和分辨率；
- 独立标签；
- 全部实际抽帧的证据链接；
- 最终层资产目录链接。

点击证据帧后，浮窗按需加载图片，并显示抽帧时间、OCR 原文、归一化文本、置信度和命中的网址/IP。点击资产目录链接会在 Windows 资源管理器中打开该目录。

### 5.5 准备隔离

审核状态包括：

- 待审核；
- 确认保留；
- 准备隔离；
- 已隔离；
- 隔离失败；
- 已恢复。

选择“准备隔离”不会立即移动文件。系统会先动态计算目录影响：

- 目录中仍有保留的资产组时，只移动选中的资产组；
- 所有资产组均准备隔离、且只剩系统杂项时，可选择整体隔离目录；
- 仍有未归属文件或额外子目录时，页面会列出内容并要求额外确认。

### 5.6 执行隔离

执行前确认页面会列出：

- 审核单元数量；
- 文件数量；
- 是否包含完整目录；
- 未归属内容；
- 隔离目标路径。

隔离前程序会重新校验源文件清单、大小和修改时间。扫描后发生变化的资产不会被移动。

隔离保留相对于扫描根的原始结构。例如：

```text
扫描根：  \\server\media\JAV
源目录：  \\server\media\JAV\2026\ABC-123
隔离根：  \\server\media\JanitorJAV_Quarantine
目标目录：\\server\media\JanitorJAV_Quarantine\2026\ABC-123
```

资产组和 CD 套装采用整组操作。任一文件移动失败时，系统尝试回滚本次已经移动的文件，并保留逐文件日志。

### 5.7 恢复

从历史任务打开已经隔离的审核单元，选择恢复。系统按照操作日志将文件移回原相对路径。

如果原位置出现同名冲突，恢复停止且不覆盖任何文件。

### 5.8 完成任务

任务完成后，Windows 通知和 Web 页面会显示摘要。

处理完隔离区后，请人工检查并移走、改名或清空 `JanitorJAV_Quarantine`。只要该目录非空，就不能在同一父目录下开始新的扫描任务。

## 6. 证据与任务记录

默认任务工作目录：

```text
%LOCALAPPDATA%\JanitorJAV\tasks\<任务ID>\
```

其中包含：

- 任务配置；
- JSONL 扫描和状态记录；
- 文件隔离、回滚和恢复日志；
- 人类可读的运行日志；
- 全部实际抽取的证据帧。

任务和证据不会自动删除。历史任务页面会显示占用空间，并允许手动删除任务工作目录。删除任务记录不会删除媒体库或隔离区文件。

## 8. 常见问题

### 为什么视频中有广告但没有被标记？

V1 只检查 10 个候选点位，无法保证覆盖任意时刻出现的广告。评测时会区分抽样未覆盖和 OCR 未识别。

### 为什么普通网址也会被标记？

这是已确认的高召回规则。JanitorJAV 不判断网站是否属于博彩网站，任意符合点分结构的文字或 IPv4 地址都会成为候选。

### 为什么短视频直接被标记？

所有小于 3 分钟的非 VR 视频都带 `duration_under_3m` 标签，同时仍进行抽帧和 OCR，供人工审核。

### 为什么 VR 视频没有抽帧？

文件名带独立 `VR` 标记的资产会跳过广告检测，只读取时长、分辨率并检查资产完整性。

### 为什么不能使用已有内容的隔离目录？

隔离区必须从空目录开始，以保证路径镜像、冲突判断、回滚和恢复过程可追踪。每次任务结束后需要人工处理隔离区。

### SMB 暂时断开会怎样？

单个读取操作会自动重试 3 次。仍失败时给对应资产添加网络错误标签，并继续处理其他文件；任务完成后可仅重试失败项。

## 9. 开发者 macOS 验证

macOS 不是正式运行目标，但可用于核心逻辑和 FFmpeg 适配层开发。

安装 FFmpeg：

```bash
brew install ffmpeg
ffmpeg -version
ffprobe -version
```

创建环境并运行测试：

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m pytest
```

CUDA OCR 和 Windows 资源管理器集成必须在 Windows + NVIDIA 环境中验证。
