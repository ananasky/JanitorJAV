# JanitorJAV 使用指南

更新日期：2026-09-03。本文描述当前实现；[V1 规格](v1-specification.md)是原始需求基线，不代表所有规划均已实现。

## 1. 安全边界

程序递归扫描视频、抽帧并执行本地 OCR。审核选择与文件移动分开，只有确认执行隔离后才移动文件，不提供永久删除功能。

风险分不是广告概率，更不是删除保证。200 分只是关键词规则命中，“客服”“代理”等词也可能误判。建议先隔离复核，再决定是否清理。删除隔离文件或任务日志后，程序可能无法恢复。

## 2. 环境与启动

目标环境：Windows 原生 Python 3.11+、NVIDIA GPU、FFmpeg/ffprobe 和 PaddleOCR。SMB 使用运行程序的 Windows 用户权限，不保存共享凭据。

```powershell
git clone https://github.com/ananasky/JanitorJAV.git
cd JanitorJAV
powershell -ExecutionPolicy Bypass -File scripts\setup-windows.ps1
powershell -ExecutionPolicy Bypass -File scripts\start-background.ps1
```

在服务所在主机打开 <http://127.0.0.1:8765>。后台脚本使用按需计划任务，不配置开机自启；前台可使用 `scripts\start.ps1`。

服务启动参数 `--device` 默认 `gpu:0`，可显式指定 `cpu`；页面没有逐任务 GPU 选择器。关闭页面、关闭屏幕或锁屏不等于停止服务；睡眠、休眠、关机和服务停止会中断运行条件。

## 3. 创建扫描与分组

输入扫描根，例如 `\\server\media\JAV`。程序创建同级 `JanitorJAV_Quarantine`，创建任务时要求该目录不存在或为空，并验证写权限。已有任务可以继续向自己的隔离区移动文件。

新任务完整扫描，不复用旧任务。视频并行数为 1–8，默认 1；每视频默认并行提取最多 4 帧，同一扫描管线内 OCR 串行调用。不建议同时开多个任务争用同一个 OCR 实例。

标准配套文件：

```text
ABC-123.mp4
ABC-123.nfo
ABC-123-poster.jpg
ABC-123-fanart.jpg
ABC-123-thumb.jpg
ABC-123.srt          # 可选
ABC-123.AI.srt       # 可选
```

同目录下带独立 `-CD1`、`-CD2` 等标记的同组视频共同审核；无 CD 标记的视频分别审核。VR 标记可在 CD 前后，同组任一分段带 VR 时整组跳过广告检测。

未经过 MDC 整理的目录也能扫描，但会产生缺 NFO/图片标签，不同名配套文件不会自动关联。杂乱目录优先按审核单元隔离，慎用“整体隔离目录”。

候选抽帧点为 5/10/15/20/25 秒及 10%/25%/50%/75%/90%，越界丢弃、接近点合并，最多 10 帧。不能保证覆盖任意时刻的广告。非 VR 短于 3 分钟、RM/RMVB、处理异常和资料缺失分别带标签，不等于确认广告。

扫描页显示完成数、总数、标签数、异常数、当前文件和视频并行数。暂停、安全取消要等待在途工作收尾，不是立即中止。继续同一任务跳过已有记录，不等于重试所有失败项。

## 4. 审核列表与证据

三个主要列表：待处理、保留、待隔离。状态下拉框还可查看已隔离、隔离失败、已恢复。默认只显示带标签记录，可取消。

支持每页 25/50/100 条、跳页、整页全选、逐条及批量保留/标记隔离。决定后的记录从当前批次移走，不立即补充；处理完点击“加载下一批”。工具栏悬浮。

识别汇总去重显示网址和关联文字，不显示次数或位置；目前每个网址的关联文字最多取 3 行，不是完整 OCR。红色抽帧链接表示该帧有网址/IP 匹配。点击浮窗查看图片及 OCR 原文；“打开目录”在服务所在 Windows 主机打开资源管理器。

## 5. 筛选与跨页选择

多个条件取交集：

| 条件 | 含义 |
| --- | --- |
| 标签筛选 | 按标签名匹配，不搜索 OCR |
| 搜索路径 | 包含匹配目录、番号分组键或关联文件路径，不区分大小写 |
| OCR 关键词 | 对全部抽帧 OCR 原文包含匹配，不区分大小写 |
| 时长≤秒 / 时长≥秒 | 审核单元合计时长上下界，包含边界 |
| 宽度≤像素 / 高度≤像素 | 各视频最大宽度/最大高度不超过阈值；未知尺寸不算低清 |

输入修改后离开输入框更新列表。OCR 搜索按一个完整字符串匹配，不支持正则或多词 OR。

1. 先设置当前列表及路径、OCR 等筛选。
2. 输入最低分数，点击“跨页全选分数≥”（默认 200）；或输入 OCR 文字点击“跨页全选关键词”。
3. 检查顶部“已选 N”，再批量保留或标记隔离。

两种跨页选择均遵守其他筛选。关键词选择不要求达到分数框的值。新一次跨页选择替换旧集合。当前页取消只取消当前页，跨页选中的其他记录可能仍选中；修改筛选后应重新跨页选择再操作。

## 6. 风险评分

读取列表时动态评分，更新规则后旧任务无需重扫。无宣传关键词时，每个去重地址单独计分：

- IPv4 或末尾为 2–24 个英文字母的地址基础 30 分，其他点分文字基础 5 分。
- 每命中一帧加 7 分，最多计 6 帧。
- 最高 OCR 置信度 ≥0.75 加 15 分，否则加 `round(置信度 × 10)`。
- 弱格式单项最高 35 分。
- 取最高单项，其他去重候选每项加 2 分（额外最多 6），总分最高 100。

存在地址候选且 OCR 出现以下任一词时，最终为 200：

```text
博彩 赌场 娱乐城 棋牌 投注 下注 送彩金 注册送 代理 客服
免费获取 国产大片 澳门 真人美女 荷官 发牌
裸聊 脱衣秀 激情视频 漂亮妹妹 幼幼 人兽
```

当前限制：只有关键词、完全没有网址/IP 候选时仍为 0，也不单独新增标签。这与“关键词单独命中也为 200”的期望有差距。可取消“仅显示带标签”，用 OCR 搜索检查这类记录。

高风险 ≥70，中风险 ≥45，其余低风险；200 同属高风险。短视频、资料不全等独立标签不增加 OCR 分数。0 分也不意味着无广告。

## 7. 隔离、进度与恢复

“标记隔离”只改审核状态。待隔离列表中：

- “执行所选隔离”仅执行选中且仍为待隔离的记录。
- “执行全部待隔离”作用于该任务全部待隔离记录，忽略当前筛选和分页。

批量隔离由后台逐条执行，页面每 0.5 秒查询处理数/总数、成功、失败、当前番号及失败原因。进度以审核单元计，不是字节进度；单项耗时长时进度可暂不变化。单项已记录的失败会继续下一项，作业级异常会停止。

同任务不能重复启动后台隔离作业。同一浏览器刷新后可以恢复进度，前提是服务未重启。作业状态仅存在内存中，服务重启后不能恢复进度或自动续跑；文件操作日志仍保存。操作期间不要停止服务、部署、删除任务记录，或同时恢复/整体移动同一目录。

隔离保留相对目录：

```text
扫描根：\\server\media\JAV
源文件：\\server\media\JAV\2026\ABC-123\ABC-123.mp4
目标：  \\server\media\JanitorJAV_Quarantine\2026\ABC-123\ABC-123.mp4
```

程序检查记录中源文件大小与修改时间，目标存在时不覆盖。失败后尝试回滚，回滚也可能失败；以操作日志和实际文件状态为准，不保证事务原子性。

整体隔离目录需额外确认，会包含未归属内容、子目录和系统杂项，不使用批量进度条。恢复依赖原操作日志，遇到原位置冲突不会覆盖。

失败项在状态下拉框选“隔离失败”，再用路径搜索定位。不要仅凭失败提示认定所有文件仍在原处；检查逐文件结果和回滚错误。

## 8. 日志与清理

默认目录：`%LOCALAPPDATA%\JanitorJAV\tasks\<任务ID>\`。

- `task.json`：配置、路径和扫描状态。
- `assets.jsonl`：扫描、OCR、标签和审核状态；同一资产最后一条为最新状态。
- `operations.jsonl`：隔离/恢复结果、源目标路径、错误与回滚错误。
- `evidence/`：全部实际抽帧。

服务输出日志位置参见后台启动脚本。历史任务可删除日志和证据，不删除媒体文件，但会失去恢复依据。操作期间不要删除任务记录。

当前没有独立的“仅重试失败项”页面、吞吐量/预计完成时间面板或 Windows 完成通知，不要把原始规划当成已实现功能。

## 9. 更新与开发

仅在扫描及文件操作全部结束后更新：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\stop-background.ps1
git pull --ff-only
.venv\Scripts\python -m pytest -q
# 测试通过后启动
powershell -ExecutionPolicy Bypass -File scripts\start-background.ps1
```

macOS 可验证核心逻辑，CUDA 和资源管理器集成需在 Windows 验证：

```bash
brew install ffmpeg
python3.11 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m pytest -q
```
