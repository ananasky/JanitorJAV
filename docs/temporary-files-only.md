# 仅扫描文件模式

稳定回退基线：`da1286ba5f9728ec500c6d1735f6e940247bb905`（main）。
最初在 `codex/temporary-files-only` 分支开发。2026-09-04 用户确认长期保留为可选功能，不再计划自动回退。

- 创建任务时默认不勾选“仅扫描文件”，默认执行正常探测、抽帧和 OCR。勾选后才启用文件扫描。沿用视频扩展名、CD/VR 和配套文件关联规则。
- 跳过媒体探测、抽帧和 OCR，只记录文件分组与快照；时长和分辨率为空，不适用于相关筛选。
- 任务页默认显示全部记录，避免无标签完整组被隐藏。
- 使用“搜索文件名 / 路径”缩小范围，点“跨页全选筛选结果”，检查选中总数，再批量保留或标记隔离。
- 搜索同时匹配目录和关联文件路径；不是只匹配视频名。未填条件时会选择当前列表全部记录。
- 标记隔离不移动文件，仍需明确执行隔离。整任务待隔离操作忽略当前筛选，谨慎使用。
- 不重新处理旧任务；需要新建文件扫描任务。取消勾选可使用正常扫描。

回退时先确认所有扫描和文件操作结束，再切回稳定分支部署。保留任务日志、媒体和隔离文件，不通过删除任务数据回退。临时任务回到旧代码后不应继续扫描，可查看已生成记录并按现有日志恢复文件。
